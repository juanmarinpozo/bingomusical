📌 Instrucciones

🎵 Bingo Musical

Cómo se juega
  • Cada jugador recibe un cartón con canciones diferentes.
  • El presentador pondrá canciones al azar.
  • Si una canción suena y la tienes en tu cartón, márcala.
  • Gana quien cante LÍNEA o BINGO.

📏 LÍNEA

Quien cante línea: sale a bailar durante la siguiente canción.

🏁 BINGO

Quien cante bingo: reparte castigo (bebida, reto o prueba).

⚡ Pruebas aleatorias

Durante la partida pueden aparecer pruebas aleatorias si el modo pruebas está activado.
⚙️ Ajustes de partida (opcional)
Si desactivas los avisos, el juego seguirá validando línea/bingo, pero no mostrará el modal automáticamente.
⚙️ Configuración de canciones (opcional)
Elige cómo quieres cargar las canciones (recomendado: 90 aleatorias para partidas rápidas).
Consejo: si quieres cambiar 1 canción, usa Selección exacta y selecciona tus 89 + la nueva, o entra en Gestionar selección para quitar/añadir y aplicar.
